# Sherlock Liu Personal Website

This is a static personal website. It can be published directly with GitHub Pages.

## GitHub Pages Options

1. User site: create a repository named `YOUR_GITHUB_USERNAME.github.io`, then put these files at the repository root. The site will use `https://YOUR_GITHUB_USERNAME.github.io/`.
2. Project site: create any repository name, put these files at the repository root, and enable GitHub Pages for the main branch. The site will use `https://YOUR_GITHUB_USERNAME.github.io/REPOSITORY_NAME/`.

## Files

- `index.html`: page content
- `styles.css`: visual design
- `script.js`: motion and interaction
- `assets/detective-cap.svg`: hand-drawn detective cap illustration
